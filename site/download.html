Before you open it

Your Mac or Windows may ask you to confirm you want to open BubbleFacts, because it isn't digitally signed yet. Here's exactly what to click.

  • Mac

    macOS 13 Ventura or newer.

    Download for Mac

    A disk image. Open it, then drag the app into your Applications folder.

    Need the Intel version?

    Which Mac do I have?

    Most Macs sold since late 2020 have Apple silicon, and Download for Mac is for those. To check yours:

    1. Click the Apple menu in the top-left corner of the screen.
    2. Choose About This Mac.
    3. If it says Chip: Apple M… (M1, M2, M3 or newer), you have Apple silicon: use Download for Mac. If it says Processor: Intel, use the Intel version.

  • Windows

    Windows 10 or 11, 64-bit.

    Download for Windows

    An installer. Open it to install the app just for you, with no administrator password.

  • Linux: Ubuntu and Debian

    64-bit. Tested on Ubuntu 24.04 and newer.

    Download .deb

    A package that installs like other apps on Ubuntu, Debian and similar systems.

  • Linux: other

    64-bit, with glibc 2.35 or newer. Not tested, but should work.

    Download AppImage

    A single file that runs without installing. Allow it to run as a program, then open it.

Needs macOS 13 or newer, Windows 10 or 11, or 64-bit Linux, plus OBS Studio 28 or newer on the same computer. Full system requirements.

What's new

Updating to a newer version

Your sign-in, settings and facts are kept. OBS needs no changes.

From version 2.0.0-beta.5 on

  1. When a new version is out, BubbleFacts shows a notice. Click Update now. It downloads and checks the new version while you keep streaming.
  2. Between songs, click Install now. BubbleFacts closes for a few seconds and reopens.
  3. Mac: when it reopens, your Mac asks for permission to use your saved sign-in. Click Always Allow. Allow alone makes it ask every time BubbleFacts opens.

If you installed the Linux .deb, or the notice says Get it, follow the steps below.

From an older version, or by hand

  1. Quit BubbleFacts from its icon in the menu bar (Mac) or system tray (Windows and Linux).
  2. Download the new version above.
  3. Mac: open the .dmg, drag BubbleFacts into Applications, and click Replace. Windows: run the installer. Linux: install the new .deb, or replace your old .AppImage file with the new one.
  4. Open BubbleFacts. The first time, your computer may ask you to confirm again: see Opening it the first time.

Opening it the first time

The app isn't signed yet. Signing is a paid registration with Apple and Microsoft that tells your computer who made an app. Until that's done, your computer warns you the first time you open BubbleFacts. These warnings go away once the app is signed.

Mac

On macOS 15 (Sequoia) and newer, your Mac says "BubbleFacts" Not Opened.

  1. Click Done.
  2. Open System Settings, then Privacy & Security.
  3. Scroll down and click Open Anyway next to the note about BubbleFacts.
  4. Enter your Mac password, then click Open Anyway once more.

On older Macs: right-click BubbleFacts in your Applications folder (or Control-click), choose Open, then click Open again. You only need to do this once.

Windows

Windows SmartScreen may show a blue box saying Windows protected your PC.

  1. Click More info.
  2. Click Run anyway.

Your browser may also say the file isn't commonly downloaded. In Microsoft Edge, point at the download, click …, then Keep, then Show more, then Keep anyway.

Then follow the setup guide.

For security-conscious users and developers

Check your download

This checks that the file you downloaded is complete and exactly the one published on GitHub.

Drag the file you downloaded here, or

Your file never leaves your computer. This page works out the file's fingerprint right here in your browser and compares it with the list on GitHub. Nothing is uploaded.

The file checker needs JavaScript turned on. You can still check a file by hand with the commands below.

Every file has a fingerprint (a SHA-256 checksum), worked out from its contents. Change even one byte and the fingerprint changes. GitHub lists the fingerprint of every download, so if yours matches, your file is good.

A match means the file arrived complete and unchanged from what's on the GitHub release page. It doesn't prove who made the file. App signing does that for your computer, and signing isn't set up yet.

Where the files come from

Every file is built by GitHub Actions from the public source code, with a build-provenance attestation: a signed record of how and where it was built, which anyone can check.

File names and commands

Release files have the version number in their names:

  • BubbleFacts-VERSION-mac-arm64.dmg (Apple silicon) and BubbleFacts-VERSION-mac-x64.dmg (Intel)
  • BubbleFacts-VERSION-windows-x64.exe
  • bubblefacts_VERSION_amd64.deb
  • BubbleFacts-VERSION-linux-x86_64.AppImage

Each release also includes SHA256SUMS.txt, the list of fingerprints. To check a file by hand, compare its line there with the output of one of these:

shasum -a 256 FILE
Get-FileHash FILE

The first works on Mac and Linux (or sha256sum on Linux), the second in Windows PowerShell. To check the build-provenance attestation, install the GitHub CLI and run:

gh attestation verify FILE --repo frolicchris/bubblefacts

With JavaScript off, each download button opens the GitHub Releases page, where you can pick the file. Older versions are there too.
