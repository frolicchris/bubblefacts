Requirements

System requirements

If your computer can stream with OBS, it can most likely run BubbleFacts. If it can't run the built-in AI, there's a free online option. Here are the details.

Minimum and recommended system requirements
WhatMinimumRecommended
Operating system
  • macOS 13 Ventura or newer (Apple silicon or Intel)
  • Windows 10 or 11, 64-bit
  • Linux, 64-bit, with glibc 2.35 or newer, using the AppImage
  • Any of these, kept up to date
  • On Linux: Ubuntu 24.04 or newer, which is the tested version
OBS Studio Version 28 or newer, which has the Browser source BubbleFacts uses The current version (OBS 32)
Memory (RAM) 8 GB 16 GB. The built-in AI uses about 1 to 3 GB while it writes facts. OBS and your game or music software need the rest.
Free disk space 4 GB: about 400 MB for the app, 2 GB for the AI model, plus room for logs Same
Processor
  • Mac: any Apple silicon Mac, or an Intel Mac from 2017 or newer
  • Windows and Linux: a 64-bit processor from 2015 or newer (Intel 6th generation Core or newer, or AMD Ryzen)
 Any Apple silicon Mac. On Windows and Linux, a newer processor writes facts faster.
Graphics Not required. Without a graphics card, the AI runs on the processor.
  • Mac: nothing to do. Macs use their built-in graphics automatically.
  • Windows and Linux: a graphics card with current drivers (NVIDIA, AMD or Intel, with Vulkan support) makes facts faster.
Internet Needed to read your queue from StreamerSongList and to look songs up on Wikipedia. The built-in AI downloads once, on its own, when you first open the app, and works offline after that. Same
Accounts A StreamerSongList account (free). You sign in to it with the Twitch account you use there. Optional: a Groq or Anthropic key, if you'd rather the AI ran online. You add it later in Settings, not during setup.

How fast are the facts?

When a song starts, the built-in AI takes a few seconds to write its facts. Facts arrive while the song is still playing, even on slower computers.

Time to write facts for one song
ComputerTime per song
Apple M1 Pro Mac About 5 to 8 seconds (measured)
Windows or Linux with a graphics card Expected to be a few seconds (not yet measured)
Processor only, no graphics card Expected to be longer (not yet measured)

If the built-in AI can't run

Some computers, for example ones with an older processor, can't run the built-in AI. You can still use BubbleFacts:

  1. The app tries a simpler mode that uses only the processor. This happens on its own.
  2. If that doesn't work either, the app walks you through switching to Online: Groq. It's free, with a daily limit, and does the AI work online.

Online: Groq is also a good choice if your computer already works hard while you stream. You can switch any time in Settings, under Who writes the facts. See using an online AI.

Advanced

If you already run Ollama, you can point BubbleFacts at it under Settings, then Who writes the facts. Install Ollama from ollama.com with its normal installer. BubbleFacts downloads the Ollama model for you the first time.
