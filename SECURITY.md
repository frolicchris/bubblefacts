# Security

## Reporting a problem

If you find a security problem, please report it privately using
[**Report a vulnerability**](https://github.com/frolicchris/stream-facts-overlay/security/advisories/new)
on the Security tab, not in a public issue. You'll get a reply as soon as
possible, and credit in the fix if you'd like it.

## Keeping your own setup safe

- **Never share your `.env` file**, or paste your StreamerSongList token or an
  API key into an issue, a discussion, or a screenshot. If one leaks, delete it
  on the service's website and create a new one.
- **The overlay only accepts connections from your own computer** by default,
  because it has no password. Change `HOST` only if you understand the risk,
  and only on a network you trust.
- **Only one version is supported:** the latest release. Update when a new one
  comes out.
