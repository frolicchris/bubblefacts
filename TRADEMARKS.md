# BubbleFacts trademark policy

The BubbleFacts code is free and open source under the [MIT license](LICENSE):
anyone may use, change and share it.

The **BubbleFacts name and logo** are different. They're trademarks of Christopher Feyrer, and the MIT license
doesn't cover them. This page says how you can use them.

The point is simple: when people see the name BubbleFacts, they should know
they're looking at the official project, with its fact-checking approach and
privacy promise.

## Use the name freely to talk about BubbleFacts

You don't need to ask to:

- Say you use BubbleFacts, on stream, in a panel, a video or a post.
- Write, teach or make videos about it, including reviews and tutorials.
- Say your tool works with BubbleFacts, connects to it, or is made for it,
  as long as it's clear the tool is yours and not part of the official
  BubbleFacts project.
- Share or package the official releases from the
  [releases page](https://github.com/frolicchris/bubblefacts/releases) under
  the BubbleFacts name, for example in a Linux package manager or an app
  store, as long as the app itself is unchanged and the listing says who
  packaged it.
- Show BubbleFacts on stream, including its name, bubbles and logo as they
  appear in the unchanged app.

## Forks and changed versions get their own name

Forks are welcome. If you change the code and share the result:

- Give it a different name and logo that don't look or sound like BubbleFacts.
- You may say it's "based on BubbleFacts" or "a fork of BubbleFacts".
- Remove the BubbleFacts logo and other BubbleFacts branding from it.

Changes only to how an official release is packaged don't count as changing
it. Translations are welcome as contributions to this project, so they ship
in the official app.

## Ask first

These need written permission:

- A product, service, app, extension, bot, website or account named with
  "BubbleFacts", or with a name that's easy to mistake for it.
- Domain names or social media handles containing "BubbleFacts".
- Using the name or logo in a way that suggests BubbleFacts endorses,
  sponsors or partners with you.
- Using the name or logo for a paid service or product presented as an
  official BubbleFacts offering. (Selling the code itself is fine under the
  MIT license; it's the name that needs asking.)
- Merchandise with the name or logo.

To ask, start a discussion in
[GitHub Discussions](https://github.com/frolicchris/bubblefacts/discussions)
(Q&A), and say what you'd like to do.

## Questions

If you're not sure whether something is fine, ask the same way.

This policy may change as the project grows; the version in this repository
is the current one.
